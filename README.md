# 📦 Kargo Lojistik Otomasyon Sistemi

Bu proje, lojistik sektöründeki kargo takip ve operasyonel yönetim süreçlerini dijitalleştirmek amacıyla geliştirilmiş bir masaüstü otomasyon sistemidir. Temel odak noktası, Nesne Yönelimli Programlama (OOP) prensiplerini pratik bir senaryoda uygulamak ve kullanıcı dostu bir arayüz sunmaktır.

## 🚀 Özellikler
* **Otomatik Kurye Atama:** Kurye atama süreçleri rastgele seçim algoritmalarıyla tamamen otomatik hale getirilmiştir.
* **Sağlam Mimari:** Kalıtım (Inheritance) ve Kapsülleme (Encapsulation) gibi temel OOP prensipleri üzerine inşa edilerek sürdürülebilir bir yapı kurulmuştur.
* **Hata Yönetimi (Exception Handling):** Veri bütünlüğünü korumak ve sistem çökmelerini önlemek adına Try-Catch bloklarıyla kapsamlı hata yönetimi entegre edilmiştir.
* **Kullanıcı Dostu Arayüz:** Java Swing kütüphanesi kullanılarak kolay anlaşılır ve interaktif bir masaüstü arayüzü (GUI) tasarlanmıştır.

## 🛠️ Kullanılan Teknolojiler
* **Programlama Dili:** Java
* **Grafik Arayüz (GUI):** Java Swing
* **Mimari:** Nesne Yönelimli Programlama (OOP)
* **Algoritma:** Rastgele Seçim (Randomization), Exception Handling
